# Tensor Core基準性能測定

## 1. 目的

本資料は、性能変更の成功が実証される前のNVIDIA GeForce RTX 3060 Laptop GPUの基準演算性能を記録するものです。

測定結果は、今後の実験における性能比較の基準値として使用します。

## 2. ハードウェア環境

| 項目 | 仕様 |
|---|---|
| 検証機種 | GALLERIA XL7R-R36 |
| GPU | NVIDIA GeForce RTX 3060 Laptop GPU |
| アーキテクチャ | Ampere（GA106） |
| CUDA Compute Capability | 8.6 |
| Streaming Multiprocessors | 30 |
| VRAM | 6 GB |
| OS | Windows 11 |

## 3. ベンチマーク概要

| 項目 | 記録された測定条件 |
|---|---|
| ベンチマーク方式 | GEMM |
| 行列サイズ | 4096 |
| 測定単位 | TFLOPS |
| 測定対象精度 | FP16、BF16、TF32、FP32 |

## 4. 基準性能測定結果

| 演算精度 | 実測性能 |
|---|---:|
| FP16 | 21.33 TFLOPS |
| BF16 | 20.86 TFLOPS |
| TF32 | 11.30 TFLOPS |
| FP32 | 7.19 TFLOPS |

FP32性能は演算性能の比較基準として掲載しており、Tensor Coreの処理性能を直接測定した値としては扱いません。

## 5. 実用AIワークロードの参考値

本研究の主な実用上の目的は、AI動画処理におけるGPU性能の理解です。

過去に記録された動画処理速度は約1.8 FPSです。

この数値は標準化されたベンチマーク結果ではなく、実際のアプリケーションにおける暫定的な参考値として保持しています。

実際の処理性能は、使用モデル、動画解像度、ソフトウェア設定、GPU使用率、メモリ使用量およびその他の動作条件によって変動します。

## 6. 測定結果の解釈

記録されたGEMM測定結果は、暫定的な基準演算性能を示しています。

これらの測定値のみでは、ハードウェアまたはソフトウェアによる人為的な性能制限の存在を証明することはできません。

理論上の最大演算性能と実際のアプリケーション性能の関係については、追加検証が必要です。

## 7. 今後の性能比較方法

今後のベンチマーク比較では、可能な限り同等の実験条件を維持します。

主な比較条件：

- GPUドライバーおよびCUDA環境
- ベンチマークの実装方式
- 行列サイズおよび演算精度
- GPUクロック周波数
- GPU消費電力
- GPU温度
- メモリ使用量
- アプリケーション設定
- 繰り返し測定における結果の一貫性

## 8. 測定上の制約

元のベンチマークの詳細設定、生の測定データおよび複数回測定による統計情報については、現時点では本資料に統合されていません。

そのため、本測定結果は第三者が再現可能な検証済みベンチマークではなく、暫定的な基準性能として扱います。

2026年11月24日時点では、RTX30Probe-GA106による演算性能の向上は実証されていません。

同等のGA106 Laptop GPU環境を使用した第三者による性能測定結果や比較情報を歓迎します。
