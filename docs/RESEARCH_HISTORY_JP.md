# 研究開発履歴

## 1. 研究背景

RTX30Probe-GA106は、NVIDIA GeForce RTX 3060 Laptop GPUのハードウェア動作およびTensor Coreの性能特性を調査するために開始された独立技術研究プロジェクトです。

主な研究目的は、AI動画処理におけるGPUの性能特性を理解することです。

## 2. 開発履歴

| 開発世代 | 主な研究内容 | 状況 |
|---|---|---|
| GEN1–GEN7 | UEFI診断プログラムの開発およびPCIデバイス検出 | 初期開発完了 |
| GEN8 | PCI構成空間およびCapabilityの解析 | 診断結果取得 |
| GEN9–GEN18 | GPU識別およびハードウェア診断の拡張 | 実験的開発 |
| GEN19–GEN22 | GPU初期化状態およびファームウェア関連診断 | 診断結果取得 |
| GEN23–GEN26 | 初期化動作の追加研究および実験的検証 | 実験的開発 |
| GEN27 | ファームウェア初期化動作および実行状態の解析 | 未解決 |

## 3. 確認済みの研究成果

- 実機における独自UEFI診断アプリケーションの起動成功。
- PCI Root Bridge経由での対象GPUの識別。
- PCI構成空間情報の取得。
- GPUのメモリマップドリソース情報の取得。
- GPU初期化状態に関する観測データの取得。
- Tensor Coreの基準性能測定。
- 繰り返しの実機試験および診断ログの収集。

## 4. 現在の研究状況

2026年11月24日時点で、開発世代はGEN27に到達しています。

実験ログの番号はPCI-LOG-056に到達しています。

ファームウェア初期化動作については引き続き調査中です。プロセッサの状態変化は観測されていますが、ファームウェアの正常実行は確認されていません。

観測された現象の根本原因は未解決です。

## 5. 研究方法

本プロジェクトでは、以下の反復的な研究方法を採用しています。

- 公開技術資料の調査。
- 実験的な診断アプリケーションの開発。
- 実機からの観測データ取得。
- 実験結果の比較。
- 確認済みの観測結果と未検証の仮説の区別。
- 新たな根拠に基づく研究結果の再評価。

## 6. AI支援による技術評価

研究結果の検討には、複数のAIシステムによる支援を活用しています。

- OpenAI ChatGPT
- xAI Grok
- Google Gemini

AIによる技術的な解釈は研究支援として扱い、独立して検証された技術的証拠とは区別します。

## 7. 未解決の研究課題

- GPU初期化状態の観測結果の解釈。
- GPUアーキテクチャ間における診断指標の信頼性。
- Tensor Coreの理論性能と実測性能の関係。
- 公開技術資料のGA106 Laptop GPUへの適用可能性。

現時点では、性能変更の成功は確認されていません。

第三者による独立した技術評価、情報提供および訂正を歓迎します。
